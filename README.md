# Book-App

Приложение для ведения личной библиотеки на React + TypeScript. Добавляй прочитанные и желанные книги, фильтруй по жанрам, отмечай избранное.

## Демо

[Ссылка на деплой](https://твой-проект.onreza.app) *(замени на свою)*

## Стек

- **React** — UI
- **TypeScript** — типизация
- **Vite** — сборка
- **CSS** — стили (без фреймворков)
- **localStorage** — хранение данных

## Функции

- **Добавление книг** — название, автор, год, оценка (1–10), жанр
- **Фильтр** — все / художественная / документальная литература
- **Сортировка** — по названию, автору, рейтингу, дате добавления
- **Избранное** — клик на сердечко, отдельная страница с поиском и сортировкой
- **Удаление** — крестик на карточке
- **Сохранение** — данные живут в localStorage, не пропадают при перезагрузке

## Структура

src/
├── hooks/
│ └── useLocalStorage.ts — кастомный хук для localStorage
├── types/
│ ├── Book.ts — тип книги
│ └── bookConstants.ts — жанры, цвета обложек
└── pages/
├── Books.tsx — главная: добавление и библиотека
└── Favorites.tsx — избранное
